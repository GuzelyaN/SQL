# SQL Queries Examples for Portfolio

This repository contains various SQL query examples that demonstrate the basic operations and advanced features of SQL. The examples are written for use in any relational database, and they show how to retrieve, filter, and manipulate data.

## SQL Query Examples

### Ex.1. Select all fields and all rows
SELECT * FROM students;
### Ex.2. Select all student names from the table
SELECT name FROM students;
### Ex.3. Select only the user IDs
SELECT id FROM students;
